## Running the app

Open the solution in Visual Studio on Windows and press **Start**. Arbot launches as a native desktop window containing its local interface. It does not use an external website or cloud service; the interface talks only to `127.0.0.1`, and changes are saved in the app's local `Data` folder.

To use Arbot as a website instead, run the project with the command-line argument `--web`, then open [http://127.0.0.1:5080](http://127.0.0.1:5080) in a browser. In Visual Studio, add `--web` under the project's Debug launch settings. The website and desktop app use the same HTML, API, and local data files.

The Microsoft WebView2 Runtime must be installed on the device. It is included with current Windows installations and is also available from Microsoft if the app reports that it cannot open its interface.
